**NixOS**: Setup makes the installed copy start by itself, without steam-run. It builds the loader and the libraries with Nix (`<install>/nix-runtime`, a root of the garbage collector) and points the copy to them with patchelf; uninstalling removes them. The flake's package (`nix profile install github:sachahjkl/wren`) now has the menu entry and the icons, and follows each release (`nix/release.json`).
