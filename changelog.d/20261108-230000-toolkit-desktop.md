**The desktop integration and the installed copy are the toolkit's desktop package** (`toolkit:desktop`, docs/desktop-integration.md): Wren keeps its names and marks (`src/desktop/identity.odin`), its preferences and the links that open in it; the same files, registry keys, values and `.desktop` text as before, so an installed Wren is still recognised and removed. Its process helpers (the UTF-8 arguments, the console of a program with a window) are the toolkit's process package. On Linux the Path part's directory is a root of its own (`WREN_DESKTOP_BIN_DIR`).
