**Desktop integration on Linux** : the state of the application-menu entry, the icons and the PATH symlink is watched with inotify, so Setup reflects a change at once instead of on a timer; "Add to PATH" creates a symlink in `~/.local/bin` (on the default PATH), and the XDG base directories (data, config, cache, state, runtime, downloads) are read from one place with their proper fallbacks.
