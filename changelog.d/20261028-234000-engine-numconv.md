**Engine number conversion in Odin** (`src/engine/numconv`): the exact float64 <-> string core of the JavaScript engine, ported from QuickJS-ng `dtoa.c` to native Odin and verified bit-for-bit against QuickJS over 2M+ random f64 (including subnormals, half-integers and all limits). Shortest round-tripping decimal, `Number.prototype.toString` in radix 2..36, `toFixed` / `toExponential` / `toPrecision`, correctly-rounded `atod`, and `Number()` / `parseFloat` / `parseInt` string parsing with full ECMAScript whitespace. Allocation-free (caller buffers, stack scratch); builds for `windows_amd64`, `linux_amd64` and `freestanding_wasm32`.
