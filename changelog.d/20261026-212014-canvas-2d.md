**Canvas 2D** (`src/canvas2d`, `api/canvas.widl`, `src/page/canvas*.odin`, `native/js/runtime/web_canvas.c`; `canvas.*` preferences, demo `about:demos` > Canvas 2D): `canvas.getContext('2d')` is a real software rasterizer written in Odin (premultiplied RGBA8, 16 sub-scanlines with exact horizontal coverage, no dependency): paths, fill rules, strokes with joins, caps, miter limit and dashes, `arc` / `arcTo` / `ellipse` / `roundRect`, `Path2D` (including SVG path strings), the transformation matrix, `clip`, all 26 `globalCompositeOperation` modes, linear / radial / conic gradients, patterns, shadows, `filter` (blur, brightness, contrast, grayscale, sepia, invert, opacity, saturate, hue-rotate, drop-shadow), `fillText` / `strokeText` / `measureText` with the page's fonts (drawn as outlines, monochrome), `drawImage` from images, canvases, bitmaps, `ImageData` (`getImageData`, `putImageData`, `createImageData`; limited by `canvas.max_*`), `OffscreenCanvas`, `ImageBitmap` / `createImageBitmap`, `DOMMatrix` / `DOMPoint`, and `toDataURL` / `toBlob` / `convertToBlob` (PNG and JPEG through WIC). A cross-origin image without CORS taints the canvas (`SecurityError` on reads). The shell keeps one texture per canvas and re-uploads only the dirty rectangle, so a canvas at rest costs nothing. Sizes, memory and path / text lengths are bounded by preferences (`canvas.max_dimension`, `canvas.max_pixels`, `canvas.max_page_bytes`, `canvas.max_path_points`, `canvas.max_text_bytes`). Pages that probe `getContext('2d')` at start (duck.ai's Lottie, YouTube's polyfills) now run. Not implemented: workers, `<video>` as an image source, `imageSmoothingQuality` (stored only), `resizeWidth` / `resizeHeight`.
