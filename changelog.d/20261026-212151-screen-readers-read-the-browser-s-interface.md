**Screen readers read the browser's interface** (toolkit 0.42.0: AccessKit through UI Automation, built into `wren_media.lib` as the `a11y` feature): tabs (a tab list, each tab named by its page, selected, "3 of 12", busy while loading) in the strip and the sidebar, the back / forward / reload / new tab / menu / blocker buttons named from their tooltips with their shortcuts, the address bar (a field with its text, caret and suggestions list), menus, the caption buttons, the status bar and the developer tools' tabs and buttons; NVDA and Narrator can invoke, toggle, select, expand and type. Nothing is built until a reader asks. `docs/accessibility.md`; test `tools\a11y_e2e.ps1` (a Wren with no window shown read and driven through UI Automation, in `test_all`).
