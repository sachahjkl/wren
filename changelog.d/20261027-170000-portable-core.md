**Portable core packages** (`host`, `wasm`, `js`, `idb`, `httpcache`, `blocker`, `base`, `tools/testenv`) : the Windows calls of these packages moved behind small per-system files (`*_windows.odin`, `*_linux.odin` / `*_unix.odin`), and they now build and pass their unit tests on Linux too (`tools\portability.ps1` checks every package for another system).
  - `host.thread_start`: POSIX threads on Linux (stack size, name, nice value for the lower priorities); `wasm`: SHA-256, HMAC and random bytes from `core:crypto` on every system (BCrypt no longer used there), the stack limit from `pthread_getattr_np`, Wasmtime's Linux C API (`tools/fetch_wasmtime.sh`, pinned by SHA-256); the compiled-code cache key is DPAPI-protected on Windows, a file only its owner can read elsewhere.
  - `js.timezone_name` / `timezone_offset` on Linux: `TZ`, `/etc/localtime`, `localtime_r`.
  - `base.files` (`file_write_parts`, `file_replace`, `file_read_at`, `file_stat`, `list_files`...): one file layer for the HTTP cache and the blocker's compiled lists instead of two copies of Win32 code; `base.process_memory` (resident and private bytes) and `base.temp_dir`.
