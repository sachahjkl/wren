**First pages load sooner**: the JavaScript engine's compiled code is read from the disk cache and checked on a thread of its own when Wren starts, so the first page with a script no longer waits for it (a script page's DOM ready 35 -> 7.5 ms); a script or the load event waiting for a stylesheet goes on as soon as the sheet arrives rather than at the next look (a page with a stylesheet loaded 26 -> 11 ms); what draws color glyphs is made ahead and glyph textures are cleared on the graphics card (the first paint of a page with emoji 42 -> 23 ms, the first window 4 ms sooner); `wren ctl stats` counts its threads without walking every process of the machine (20 ms -> microseconds). The numbers, and what was measured and not kept: `docs/performance.md`.
