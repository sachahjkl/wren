**Resizing the window or the developer tools' splitter over a page with a container query (sacha.house) no longer restyles the whole document at every step** (`style/container.odin` `restyle_containers`, `page/styles.odin`; preference `style.container_queries.partial`, on by default): sacha.house's ASCII logo is a `container-type: inline-size` box with `font-size: 1.5cqw`, so each width change gave the container a new size and `engine_set_container_sizes` asked for a full restyle (about 6 ms for 132 elements and 800 MB of styles made in a 6 s drag; CPU p95 of a frame 13.8 ms against 0.9 ms on about:home). Only the descendants of a container can read its size: its subtree alone is restyled now, in place (CPU p95 2.5 ms, no full pass during the drag). What cannot be scoped (container gone, root element, counters, rules changed) still takes the full pass.
