**Pages whose scripts rebuild the DOM run faster in less memory**: the nodes a script drops go back once they double the document (a collection asked for after the script's task), so what style and layout keep per node stays the document's size (a page that rebuilds 10 000 nodes a frame: 28 -> 43 frames/s, 1.27 GB -> 305 MB, layout 28 -> 11 ms a frame). Style passes keep their threads' memory from one pass to the next (a full pass 12 -> 6 ms on that page); Element Timing looks only at the elements that ask for it and Largest Contentful Paint skips the boxes that cannot win; the images and fonts a style pass may need are looked for in what changed instead of in every element (a page of 17 000 nodes changed once a frame: 1.70 -> 1.08 ms of CPU a frame). The numbers: `docs/performance.md`.
