**Loop JIT of the Odin JavaScript engine** (`javascript.jit.enabled`, `src/engine/jsrt/jit.odin`): a hot numeric loop of `jsrt` (found by sampling the interpreter's back edges) is translated to a WebAssembly function that the host compiles and attaches to the engine's table (`Engine_jitCompile` / `Engine_jitPoll`, the contract of the QuickJS engine's JIT); ints, doubles and bools live in Wasm locals, arrays and typed arrays are read and written in place, and a speculation that fails (int overflow, -0, a type change, an index out of range) deopts to the interpreter at the exact instruction. On `examples/jsbench/micro.js` the int loop goes from 46 to 0.7 ns per iteration, the float loop from 50 to 3 ns, nested loops from 57 to 1 ns, array and typed array reads from 68 and 77 to 1.3 and 1.1 ns; loops that call functions or touch properties stay interpreted.
  - `tools\build_js.ps1` takes `-OdinOpt` and `WREN_ODIN_FLAGS` (extra Odin flags, `;`-separated) to build the Odin engine with another optimisation level.
