type: Changed

**The browser shell is now platform-neutral where it called Win32 directly** (`src/browser`): file downloads, the history / session / palette / global-history stores, the Save and Open dialogs, the colour picker, the date and time-of-day formatting, the window-manager operations (raise, visibility, bounds, DPI simulation), the frame pacing timer, the status-bar settle timer, process memory and CPU, the mouse back/forward buttons, dropped files, the appearance watch and the developer-tools media preview all go through neutral services (`base.files`, `base.process_*`, `host` timers, `platform.*` dialogs / window ops, `core:time` with the JavaScript time-zone) or a documented `*_windows.odin` / `*_other.odin` split that keeps Windows identical and states honestly what a system does not have yet (no system colour picker or extra mouse buttons on Linux, no CDP-over-TCP, best-effort tab tear-off on Wayland). `odin check src/browser -target:linux_amd64` now passes but for the build-artifact `#load`s; Windows is unchanged.
