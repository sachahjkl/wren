**Wren's Rust code is one Cargo workspace, `native/`, built into one library** (`native/Cargo.toml`, `native/Cargo.lock`, `tools/build_native.ps1` -> `build/native/wren_native.lib`): the image decoders (`native/media`, now an ordinary library) and the toolkit's text backend and accessibility adapter (path dependencies, the features `text` and `a11y`) are picked by the assembly crate `native/wren_native`, the only static library; `tools/build_media.ps1` became `tools/build_native.ps1`, `native/media/rust-crates.txt` is `native/rust-crates.txt`. The CI's cache of the library is keyed on the toolkit's crates too (a change of the toolkit's text or accessibility code restored a stale library that was then rebuilt from nothing at every run). `docs/architecture.md`, "The Rust library".
