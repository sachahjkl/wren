**Odin regexp and Unicode engine** (`engine/regexp`, `engine/unicode`) : a from-scratch Odin port of QuickJS's `libregexp` and `libunicode`, replacing the C. Full ECMAScript regular expressions (classes, assertions, lookahead/lookbehind, named and numbered back references, quantifiers, flags `dgimsuvy`, `\p{...}`, Annex B) compiled to bytecode and run by a bounded backtracking interpreter with caller-controlled step and stack budgets (no native recursion); Unicode properties, case folding, ECMAScript `canonicalize`, NFC/NFD/NFKC/NFKD and compact interval character sets with set operations for the `v` flag. Tables are generated from the pinned Unicode 16.0.0 database (SHA-256 verified), not copied. Builds for Windows, Linux and freestanding wasm32. Judged byte-for-byte against the QuickJS C over ~2M inputs with zero regexp/normalization/range divergences.
