**DuckDuckGo works** (a result page of it was empty, then hung or ate memory): `NamedNodeMap` named properties (`element.attributes.onsubmit`: jQuery 1's support test threw), `DOMParser` (`parseFromString` for `text/html`: an inert document, scripts do not run, no declarative shadow roots; the XML types throw `NotSupportedError` as `createDocument`), `performance.timing` with the real time of each step of the page's life cycle (and `performance.measure` taking its names, as Next.js does), `javascript.touch_events` (`auto`: pages see `ontouchstart` only on a computer with a touch screen, so they no longer take their phone path), scripts see the window's client area as their viewport before the first paint, a `<link rel=stylesheet>` a script inserts no longer holds back the first paint (only the parser's do, or `blocking=render`), and a parser `<link>` a script turns into something else no longer holds the scripts that wait for stylesheets for ever.
