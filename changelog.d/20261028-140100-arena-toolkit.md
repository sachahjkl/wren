type: Changed

**Lifetime primitives moved to the toolkit** (`toolkit:arena`): the `Scope` tree (arena plus cleanups, child scopes) and the generational `Pool` / `Handle` now live in the toolkit's `arena` package, a cross-application concern, so another application reuses them. Wren's `base` keeps the historic names (`base.Scope`, `base.scope_make`, `base.on_close`, `base.Pool`, `base.Handle`, `base.pool_insert`, ...) as aliases, so all callers do not change. The memory tracker (`base.process_context`, `base.mem_report`) stays in Wren (its config and lint are Wren's). No behaviour change.
