**`document.domain` setter**: a page and its frames of other ports or subdomains of one site that set the same `document.domain` reach each other's documents and windows (HTML's same origin-domain), and a navigation between them fires the target's `navigate` event; a value that is not the host or a registrable suffix of it, or a sandboxed document, throws a `SecurityError`; under `Origin-Agent-Cluster: ?1` the assignment changes nothing.
