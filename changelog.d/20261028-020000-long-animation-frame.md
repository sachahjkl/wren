**Long Animation Frames** (`PerformanceObserver` type `long-animation-frame`, `PerformanceLongAnimationFrameTiming`, `PerformanceScriptTiming`, prefs `performance.long_animation_frame_entries`, `performance.long_animation_frame_script_min_ms`) : a task of the page (and the render it triggers) that monopolises the main thread for 50 ms or more is reported as a long animation frame, with `startTime`, `duration`, `renderStart`, `styleAndLayoutStart`, `styleDuration`, `layoutDuration`, `blockingDuration`, `firstUIEventTimestamp`, `scripts` and `toJSON()`. Each `scripts` entry (`PerformanceScriptTiming`) names what ran — `invokerType` (`classic-script`, `event-listener`, `user-callback`...), `invoker` (the event type, the timer handler, `requestAnimationFrame`...), `executionStart`, `sourceURL`, `duration`, `window` and `windowAttribution` — for every invocation of at least `performance.long_animation_frame_script_min_ms` (5 ms). Measured natively from the shell's task loop (`src/page/timeline_loaf.odin`), no JavaScript and no polling. `PerformanceObserver.supportedEntryTypes` lists it.
