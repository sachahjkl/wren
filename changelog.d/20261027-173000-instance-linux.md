**One Wren per profile on Linux** (`instance.acquire`, `instance.pump_messages`) : the second start hands its addresses to the first through a Unix socket in the user's runtime directory (`$XDG_RUNTIME_DIR/wren`, mode 0700), ownership is a `flock` the kernel releases when the owner ends, crashed or not; the same answers and waits as on Windows (owner starting, closing, silent). `remote.profile_name` keeps the case of Linux paths.
