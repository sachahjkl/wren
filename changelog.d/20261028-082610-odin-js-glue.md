**Colle JavaScript en Odin** (`native/js/odin`, `tools/build_js.ps1`) : la colle du moteur JS peut désormais s'écrire en Odin et se lier dans le même module Wasm que QuickJS. Première couche d'aide `wj` et premier domaine porté depuis le C (`CountQueuingStrategy` / `ByteLengthQueuingStrategy`) ; voir `docs/js/odin-glue.md`. Le moteur se compile sans LTO inter-unités quand un objet Odin est présent (doublons `memset`/`bzero` entre le runtime wasm d'Odin et wasi-libc).
