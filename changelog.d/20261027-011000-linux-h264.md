**H.264 on Linux** (`media.h264.backend`) : `<video>` H.264 decodes through Cisco's openh264 shared library, loaded at run time by dlopen so the browser runs without it; the GPU's VA-API decoder is probed and preferred where present (the decode path itself still falls back to openh264 until it is wired). `media.h264.openh264_path` names the library when it is not on the usual paths.
