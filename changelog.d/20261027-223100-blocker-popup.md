**`$popup` filters stop pop-up windows and tabs** (`blocker.popup.enabled`, `src/blocker/popup.odin`): a `window.open` (or any child window a page opens) whose target a `$popup` filter names is stopped before a tab is created, with uBlock Origin / Adblock Plus semantics (`$popup`, `$popup,domain=`, `$~popup`, exceptions `@@||x^$popup`). A pop-up you open with a click to the same site is never stopped; one a script opens on its own is. Counted and logged like the other blocks.
