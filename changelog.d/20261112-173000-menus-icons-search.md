**Menus with icons, and a filter in every context menu**: each entry of the context menus, the main menu and the developer tools' menus has an icon, the same one the command palette shows for that action; typing in an open context menu filters its entries. The page and tab menus now take their words, shortcuts and conditions from the browser's commands, so "Close tab" in a tab's menu closes that tab, not the current one.
