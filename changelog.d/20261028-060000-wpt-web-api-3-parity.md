**Web platform tests** (`urlpattern`, `scheduler`, `web-locks`): URLPattern `exec()`/`test()` now echo the original input(s) back in `result.inputs` (a URLPatternInit stays an object), raising URLPattern parity from 42% to 77% of subtests. `TaskController`'s signal is a real `TaskSignal` so `signal.priority`, `signal.onprioritychange` and `TaskSignal.any()` work; `setPriority()` reprioritizes the queued tasks and throws `NotAllowedError` when called from within a `prioritychange` handler; `scheduler.yield()` inherits the running task's signal and priority. Web Locks grants a request through the lock task queue when a signal is present (a synchronous abort beats the grant, and an abort is ignored once granted), and a stolen lock rejects the previous holder's promise with `AbortError`.
