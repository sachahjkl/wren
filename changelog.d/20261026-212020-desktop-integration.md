**Desktop integration** (`src/desktop`, a box in `about:config` and two palette commands): Wren is one portable executable, and one switch adds or removes what makes it part of the user's desktop, in the user's own profile and without administrator rights. Windows: a shortcut in the Start menu (the executable's icon, and the AppUserModelID the windows declare, so that pinning and grouping work) and the registration as a candidate browser (`HKCU\Software\Clients\StartMenuInternet`, `RegisteredApplications`, the `WrenHTML` ProgID, URL schemes http and https and the file types of `browser.desktop_integration.file_types`): Wren then shows in Settings > Apps > Default apps, where the user picks the default (it never makes itself the default); a button opens that page. Linux: the XDG `.desktop` file (`MimeType=` for http, https and the file types) and the hicolor icons, then `update-desktop-database`. The box is ticked by what is on the disk, not by a preference; files that run another executable (the program was moved or updated) show "points to <path> - Update". The first run of a release build outside the installed copy opens Setup (below) instead of integrating silently (`browser.desktop_integration.on_first_run`). `wren --desktop-integration=install|remove|status` does it without a window, for an uninstall script. Removal deletes only what carries Wren's mark.
