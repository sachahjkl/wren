**XMLSerializer** (`serializeToString`): a node and its subtree as XML, each element's namespace declared where it changes (`xmlns` on an HTML element or an `<svg>` of an HTML page), SVG names in their case, `xlink:` attributes declared, empty elements closed as `<x/>` and HTML void ones as `<br />`, text and attributes escaped, a template's contents, a document with its doctype.
