type: Changed

**Scripts that make and drop many DOM nodes run faster**: a node's JavaScript object that carries nothing of its own (no property, listener, other prototype or weak reference) no longer has to be kept with its tree, so the collection that frees dropped nodes costs less than half what it did (a page that rebuilds 10 000 nodes a frame: script 35.8 -> 25.1 ms a frame, 49 -> 60 frames/s). `createElement` and `getElementsByTagName` lower-case names in ASCII only, as the DOM Standard says (`createElement("Ä")` keeps its name). The measurements, and why the crossings between the engine and the browser were not the cost: `docs/performance.md`.
