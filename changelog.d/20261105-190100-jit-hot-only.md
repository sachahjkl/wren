**The JIT waits for code that is really hot** (`javascript.jit.call_threshold` 100 000, `javascript.jit.loop_threshold` now counts the interrupt checks that met a loop): translating the thousands of functions and loops a load runs a few thousand times cost more than the compiled code gave back. The CPU of a heavy page's load is about halved, its load no later; code that is hot is compiled as before.
