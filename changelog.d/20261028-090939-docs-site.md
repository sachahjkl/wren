**Documentation site** (`site/docs`): the Markdown files under `docs/` are generated into a static, searchable documentation site by a new Odin tool (`src/tools/docsite`), with a tree sidebar, a per-page table of contents, breadcrumbs, previous/next links, an Edit-on-GitHub link, generation-time syntax highlighting, client-side full-text search, a light/dark theme following the OS, and the WPT conformance chart and pass-rate table built from the git history. Linked from the header and footer of every page; regenerated and link-checked by `tools/docs_site.ps1` and verified up to date in CI.
