**The JIT reads DOM attributes** (`src/engine/jsrt/jit.odin`): compiled code calls the native getters it finds on an object's prototypes (`node.firstChild`, `list.childNodes.length`, `map.size`), reads through the Web IDL prototypes of DOM nodes (dictionaries, guarded by a version of their keys) and treats DOM wrappers as ordinary objects; an exception in a getter unwinds exactly once, as if the interpreter had called it. A loop that walks a list of nodes reading four attributes 750 -> 530 ns an iteration, `m.size` in a loop 115 -> 48 ns; a loop that reads the global `document` is not compiled yet.
