**One Wren per profile** (`browser.single_instance`, on by default; `src/instance`): a link opened from another program, a `.html` file or `wren.exe <address>` while Wren runs opens a tab in the running window (restored if minimized, brought to the front) and the second process ends at once with exit code 0, instead of a second window on the same profile. The key is the channel and the profile folder, so `--profile X` and every test stay independent; only the same executable hands over (another copy opens its own window); a Wren that does not answer within three seconds does not hold the second start, which opens its own window and says so. `--new-window` (or `--no-single-instance`) opens a separate window; `WREN_SINGLE_INSTANCE=off` turns it off for scripts (`tools\test_env.ps1` sets it). Several addresses on the command line open one tab each.
