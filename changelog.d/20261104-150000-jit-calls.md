**The JIT compiles loops that call** (`src/engine/jsrt/jit.odin`): a small function called in a compiled loop (straight-line code that only reads properties, globals and elements and computes: `add(a, b)`, `this.x * this.x + this.y * this.y`, a method that calls another such one) is inlined, the callee checked to be the function it was inlined for; `Math.abs`, `floor`, `ceil`, `trunc`, `sqrt`, `min`, `max` and `imul` are computed inline; a native function (`a.push(x)`, `m.get(k)`, `JSON.parse(s)`) is called through a helper of the engine, its exceptions caught by the interpreter as if it had made the call. A loop that calls a function it does not inline stays interpreted (the interpreter's own call is cheaper). `micro.js`: a call of a small function 84 -> 1.3 ns, a method of a prototype 185 -> 4.1 ns, `Math.floor` / `Math.abs` 153 -> 3.3 ns; `realworld.js`: methods of a class 330 -> 6.9 ns.
