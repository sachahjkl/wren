**The Network panel's font preview reads WOFF, WOFF2 and collections** (`devtools.network.preview`): the preview now decodes WOFF 1.0 and WOFF2 web fonts through the same path the page loader uses, and opens TrueType / OpenType collections (`.ttc` / `.otc`) with a face selector (a row of buttons, or a dropdown when there are many faces); it also shows the family, style, version, licence, variable-font axes and glyph count of the chosen face, with a precise message for a corrupt font, a missing table, a face out of range or one over the size limit.
