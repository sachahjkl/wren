**The JIT compiles loops that read and write properties** (`src/engine/jsrt/jit.odin`): a named property read or written on an object (`o.x`, `o.x = v`, a method's `this.x`, `a.length`, an array reached through an object, a global variable, a closure's variable) is a check of the object's own shape against the shapes the site was compiled for, then the slot at a constant index, in the object or in the prototype that holds it (its shape checked too); objects, strings, `undefined` and `null` are values the compiled code carries, compares (`===`, `== null`) and tests; a site that meets a shape or a type it was not compiled for leaves the loop to the interpreter, learns it and the loop is compiled again (a few shapes a site, a few times). `micro.js`: property get 54 -> 1.9 ns, set 25 -> 1.4 ns, a get over four shapes 59 -> 2.1 ns, a global read and written 41 -> 2.5 ns; `realworld.js` (new): particles updated in place 282 -> 14 ns, parsed records summed 86 -> 5 ns.
