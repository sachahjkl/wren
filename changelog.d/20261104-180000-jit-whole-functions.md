**The JIT compiles whole functions and calls compiled code directly** (`src/engine/jsrt/jit.odin`): a function without loops of its own is compiled whole once it has been called `javascript.jit.call_threshold` times (now 500 by default), and entered at its call, from the interpreter or from compiled code; compiled code calls such a function itself (any closure of it): it pushes the callee's frame as the interpreter does, calls the callee's code through the engine's table and pops the frame, so recursion (`fib`), callbacks and closures called from compiled loops run compiled. A recursion deeper than compiled code nests on the host stack goes on interpreted, to the same depth limit. `micro.js`: recursion (`fib`) 78 -> 26 ns a call, a closure counter 73 -> 23 ns.
