type: Changed

**File helpers moved to the toolkit** (`toolkit:fsx`) : the whole-file and positional operations the stores rely on (atomic write, `read_at`, `stat`, `make_dirs`, `list_files`), the recursive delete and the temporary directory now live in the toolkit's platform-neutral `fsx` package, so another application reuses them. `base.file_*`, `base.temp_dir`, `base.remove_tree` and `testenv.remove_tree` / `path_kind` stay as thin aliases, callers do not change; `remove_tree` no longer follows a junction or symbolic link to a directory (it removes the link, not its target).
