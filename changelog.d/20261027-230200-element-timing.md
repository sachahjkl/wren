**Element Timing** (`PerformanceObserver` type `element`, `PerformanceElementTiming`, the `elementtiming` content attribute, pref `performance.element_timing_entries`) : an element carrying `elementtiming` (an image or a block of text) makes one entry the first time it is painted, with `renderTime`, `loadTime`, `intersectionRect`, `identifier`, `naturalWidth`, `naturalHeight`, `id`, `url`, `element` and `toJSON()`. Fed natively from the layout the shell painted. `PerformanceObserver.supportedEntryTypes` lists it.
