**Content blocker** (`src/adblock`, `src/blocker`, `blocker.*` preferences, shield icon at the end of the address row, `about:blocker`; [docs/blocker.md](docs/blocker.md)): native blocking of advertising, trackers and malware. The engine is an independent Odin package (ABP / uBlock Origin / AdGuard syntax: anchors, wildcards, regular expressions on a linear-time VM, type / party / domain / method options, exceptions, `important`, `badfilter`, `redirect`, `removeparam`, `csp`, `header`, entities, procedural selectors, scriptlets, `!#if` / `!#include`); lists compile in about 0.3 s to one binary index (24 MB for EasyList + EasyPrivacy + uBlock + AdGuard Base + Peter Lowe + URLhaus: 182,000 network and 73,000 cosmetic filters) that loads in 13 ms from the profile, and a request is matched in about 4 us without allocating (token, host and 4-byte-window tables behind bloom filters). The loader consults it before DNS and connection for documents, frames, scripts, images, fonts, media, fetch / XHR, beacons, WebSockets and workers (`fetch.Interceptor`; the DevTools observer gets `Observed.blocked_by`), answers with neutral stand-ins, strips tracking parameters, adds `Content-Security-Policy` and blocks on response headers. Element hiding is a user-origin stylesheet in force at the first style computation (generic selectors only when the page has that class or id), procedural selectors are evaluated natively on the DOM, scriptlets run before the page's scripts, blocked frames and images leave no box. Lists (a catalogue of 34, custom ones by URL) are downloaded in the background with conditional requests, checked, compiled on a thread of its own and cached. The panel has the power switch of the site, counters, a graph, per-site switches (element hiding, scriptlets, remote fonts, large media, hard mode), the matrix of hosts by type (click to block / allow / reset), the element picker and the log; the dashboard has settings, lists, an editor for the user's filters, the dynamic rules, the whitelist, the live journal, statistics, and export / import of the whole configuration as one file. `tools\blocker_perf.ps1` and `WREN_LOAD_REPORT` measure page loads with and without the blocker.
