**Elements with the same style share it**: elements whose styles are made of the same things (the same parent style, the same matching rules, the same style attribute) get one computed style instead of a copy each, and the inherited properties are shared with the parent until an element sets one. A page that rebuilds a list of 2 500 items every frame makes 0.1 MB of styles a pass instead of 11 MB, and its style stage takes 3.3 ms a frame instead of 8.8 (the restyle no longer works out, item by item, that so much was inserted that a full pass is due). The numbers: `docs/performance.md`.
