**The Odin SDK is a package per area of the web API** (`sdk/odin`, the `wren` collection): a page imports what it uses, `import "wren:dom"`, `import "wren:fetch"`, `import "wren:canvas"`..., instead of the one package `web:web`, and is built with `-collection:wren=<path to sdk/odin>` instead of `-collection:web=...`. Each module of `api/*.widl` is the package of its name, except `wren:core` (the modules `web`, `async` and `events`: errors, host objects, promises, buffers, event targets and events, what every other package uses) and `wren:webcodecs` (the six WebCodecs modules). A name loses an interface prefix that repeats its package's name (`fetch.Fetch_promise` is `fetch.promise`, `console.console_log` is `console.log`, `url.URL_parse` is `url.parse`) and keeps one that names one interface among several (`dom.Node_appendChild`, `dom.Document_getElementById`); `docs/api/README.md` has the rule and each function's page its Odin name when it differs.
