**Dragging the developer tools' separator no longer freezes the page for 50 to 100 ms at a breakpoint** (`style/media_gate.odin`, `restyle_dom.odin` `restyle_roots`, pref `style.media_queries.partial` and `style.media_queries.parallel_min`): a width that crossed a media query breakpoint (Tailwind's `sm:` 640 px, `md:` 768 px) rebuilt the rule index and computed the style of every element again (sacha.house/projects, 1 800 elements: 74 to 100 ms, once per breakpoint and direction, in the Style phase or, when a script read the layout first, in "Tasks, timers and input"). The rules of an `@media` block of style rules now stay in the index with a gate that the environment flips; only the elements that a rule of a flipped block matches are restyled, and below them only what inherits a changed value, on the style threads from 32 such elements. The 768 px crossing costs 1 ms of style, the 640 px one (a font size changes below 196 elements) 9 ms instead of 75. Blocks with `@layer`, `@keyframes`, `@font-face` or `@property` inside, `media` on `<link>` or `<style>` and shadow trees' rules keep the full restyle.
