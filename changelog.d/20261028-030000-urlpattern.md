**`URLPattern`** (`URLPattern`, `URLPatternResult`): the URL Pattern Standard, native (`src/url/pattern*.odin`) — construction from a shorthand string or a `URLPatternInit` with a `baseURL`, `test()` / `exec()` against a URL string or an init, the eight component getters, `hasRegExpGroups`, named and regexp groups, `ignoreCase`. The pattern tokeniser, parser and matcher (a small backtracking regexp engine for custom groups) run in the host; no JavaScript.
