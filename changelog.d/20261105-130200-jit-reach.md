type: Changed

**The JIT compiles what real pages run**: hot code of real sites stayed interpreted, refused for one instruction or given up after sixteen deopts.
  - No instruction keeps a region from being compiled: what the translation cannot do is made by the interpreter's own code from the compiled code, or is where the code leaves (`try` in a loop, closures, `typeof`, `instanceof`, `in`, `for-of`, `for-in`, `let`, calls of any function).
  - Functions with loops are compiled whole, nested loops with them.
  - A function's first runs at the threshold are recorded: a site no longer costs an exit and a translation each.
  - A site that keeps missing goes through the engine's code instead of leaving; a region is given up for the share of its entries that leave, not their number.
  - `WREN_JS_PROFILE` and `jsengine run -jit-trace` say why code stays in the interpreter.
