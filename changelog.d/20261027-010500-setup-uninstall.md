**Silent uninstall** (`wren --uninstall [--purge]`): removes the installed copy without a window — the desktop integration, the PATH entry, the Settings > Apps record and the files Setup placed — and keeps the profile unless `--purge` is given. Exit codes: 0 done, 1 failed, 5 done with some files in use (removed when the running copy closes). Also `--desktop-integration=uninstall`.
