**Web Animations** (`element.animate()`, `Animation`, `KeyframeEffect`, `document.timeline`): keyframes in both forms (a list, or values per property) with their offsets and easings, timing (delay, end delay, duration, iterations, iteration start, direction, fill, easing), `play()`, `pause()`, `reverse()`, `finish()`, `cancel()`, `playbackRate` / `updatePlaybackRate()`, `currentTime` / `startTime`, the `ready` and `finished` promises, the `finish` / `cancel` / `remove` events (`AnimationPlaybackEvent`), replaced animations removed (`persist()`, `replaceState`), `commitStyles()`, `element.getAnimations({subtree})` and `document.getAnimations()`. The timing model is the browser's (`src/page/web_animations.odin`); the effects play on the style timeline above the CSS animations (`src/style/script_anim.odin`), in a hidden tab too. `AnimationEvent` and `TransitionEvent` now give `animationName` / `propertyName`, `elapsedTime` and `pseudoElement`, and can be constructed.
