type: Changed

**Scripts that build much of their page every frame run faster**: a new element or text node and its JavaScript object are made in one call to the browser instead of four, `document` is no longer asked of the browser at each read, the JavaScript engine calls the DOM's attribute getters and the window's `document` without leaving its fast loop, and converts the values of DOM calls and finds a platform object's data with fewer calls. A page that builds 10 000 nodes a frame: its script went from 11.1 to 8.6 ms a frame, the collection that frees the nodes it dropped from 4.2 to 3.7 ms. The numbers, and what was measured and not kept: `docs/performance.md`.
