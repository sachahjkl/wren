**The JIT compiles code that makes objects** (`src/engine/jsrt/jit.odin`): `new F(...)` of a plain constructor, object literals and array literals in compiled code make their objects through the engine's allocator (a helper of the engine, the collector's rules unchanged), and a property written that the object does not have yet is appended through the shape's transition (a constructor's `this.x = x`). A loop that makes objects stays compiled; `new Point(x, y)` in a loop 404 -> 112 ns, `{a, b, c}` 261 -> 55 ns, `[i, i + 1, i + 2]` 123 -> 80 ns.
