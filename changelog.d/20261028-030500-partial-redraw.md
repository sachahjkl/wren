**Partial redraw of the window** (`browser.gpu.partial_redraw`): when only a small part of the window changed since the last frame (a blinking caret, a hovered control, a progress bar, a `<video>` in a corner, a local CSS animation), the browser now repaints and presents only the changed rectangles instead of the whole window, saving GPU power and bandwidth. The retained-picture compositor marks the page's changed chunks and immediate items; the chrome is marked around the page. `auto` (the default) turns it on where the GPU backend supports it (Direct3D 11 always; WebGPU through a kept render target); `on` forces it, `off` keeps the old whole-window redraw. A frame with nothing changed still draws nothing. `browser.gpu.partial_redraw_verify` (or `TOOLKIT_DAMAGE_VERIFY=1`) renders every frame in full too and reports the first pixel that differs, for development. `src/browser/partial_redraw.odin`, compositor damage in `src/browser/compositor.odin`; built on the toolkit's `render`/`draw` damage API.
