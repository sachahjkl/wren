**JavaScript runs faster**: the JavaScript engine's fast loop no longer calls anything itself (calls, returns, DOM getters go through procedures of their own that save its state in memory), so the code generator keeps its values in registers whatever the code around it, and DOM objects' properties are found in that loop without asking their class. The engine's micro-benchmarks run 14 % faster (a loop of integer additions 39 -> 31 ns an iteration), its larger benchmarks 9 %. `wrentool bench perf` has page loads timed from the navigation (`p10k_nav`, `nav_*`, `-Action navigate`). The numbers, and what was measured and not kept: `docs/performance.md`.
