**Licence mail: a Durable Object per purchase, a retry queue and automatic resend** (`licence/worker`): the licence Worker now hands each Paddle transaction to a `LicenseOrder` Durable Object whose input gate serialises it, so two webhooks delivered at the same instant issue one licence and send one mail (KV alone could not make that atomic). A mail that cannot go out now is queued and retried on the object's alarm with exponential backoff (1, 5, 30, 120, 720, 2880 minutes, configurable), capped, then dead-lettered; a bounce reported to `POST /mail/bounce` marks it failed. New admin endpoints behind `ADMIN_TOKEN` list and re-queue the dead-letter (`GET`/`POST /admin/dead-letter[/retry]`), `/resend` can require the token and always goes back through the queue, and the buyer's name and address are purged after `PII_RETENTION_DAYS` (RGPD). Needs the Workers Paid plan (Durable Objects); see `docs/licence.md` for the migration, the secrets and the failure scenarios.
