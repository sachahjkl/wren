type: Changed

**Scripts that build and drop many DOM nodes run faster**: `document` and `window` no longer ask for named properties nobody implements on every property read, a wrapper's interface is found by the element name's first byte, an insertion walks the inserted nodes once instead of three times, a node's script object takes one allocation instead of three, the engine's API reads a value without decoding it, and a DOM getter is called where it is found. A page that rebuilds a list of 2 500 items every frame: its script 17.6 ms a frame instead of 26.7, 122 frames/s instead of 93; the collection of the dropped nodes 5.3 ms instead of 8.1. The numbers: `docs/performance.md`.
