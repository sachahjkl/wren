**`-wren-shader`: a real shader for the browser's own pages** (`src/style/wren_shader.odin`, `src/browser/shaders.odin`, `src/browser/shaders/*.wgsl`; toolkit 0.25.0 `render.create_app_shader` / `draw.app_shader` / `render.create_texture_data`; [docs/shaders.md](docs/shaders.md)): `-wren-shader: <name> <number>*` fills a box with a fragment shader of the browser, over its CSS background, inside the rounded clip of the bottom background layer, before its border and content. It exists only in the browser's own pages (about:wren, about:home, about:demos, about:about: `page.Settings.internal_address`): in any other document the declaration is invalid and has no effect, and a name only selects among the shaders Wren ships (each declared in the registry with its arguments, textures and passes), so a web page cannot bring a shader of its own. The numbers are the shader's arguments, written with `var()` (`-wren-shader: card-foil var(--sweep) var(--bx) var(--by) var(--live) 1`) so that registered custom properties animated by CSS or changed by a script reach the computed value and ask for a repaint; the textures (the card's normal map) are made natively and kept in the renderer. Where the shader cannot be had the box keeps its CSS background. `about:wren?card=sample` shows the licence card of a sample licence, to see the shader without a licence.
