**Styles take half the memory**: the properties few elements set (background layers, transforms, transitions and animations, grid, masks, effects, anchors) are kept once and shared until an element sets one, so an element's style costs what it sets (1.5 KB instead of 2.8 KB: a full style pass of a page rebuilding 10 000 nodes a frame makes 11 MB of styles instead of 20, and is 6 % faster; 302 -> 275 MB in all). Layout on the page thread keeps its temporary memory from one pass to the next instead of mapping and freeing it every pass. The profiler samples the threads in proportion to the time they run. The numbers: `docs/performance.md`.
