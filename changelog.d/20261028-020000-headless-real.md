**Real headless mode** (`--headless`, `wren ctl run` / `start`): a Wren with no window at all, not a hidden one, so it runs where there is no desktop session (a service in session 0, an SSH login, a CI runner). It renders to an offscreen target the capture reads (`platform.open_window_offscreen`, `render.init_offscreen`, `render.resize_offscreen`); the window's size, place, state and DPI are emulated and resize the target (`wren ctl window --size WxH --dpi n`, a remote `Emulation.setDeviceMetricsOverride`); input comes through the same synthetic-event path as before (`platform.inject_event`). The loop waits on an event the server thread signals, in place of a window's message queue. Capture now works on both render backends, so a headless Wren takes pictures with Direct3D 11 or wgpu.
