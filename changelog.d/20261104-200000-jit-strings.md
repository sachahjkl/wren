**The JIT compiles loops that concatenate and compare strings** (`src/engine/jsrt/jit.odin`): `s += x` and `a + b` with a string are made by the engine's own concatenation (its ropes and append buffers), a conversion that could run code or throw left to the interpreter so that it happens once, and `===` / `switch` compare strings by value. A switch on strings 105 -> 14 ns, `s += "a"` with `charCodeAt` 245 -> 127 ns.
