**Faster layout of pages with columns and of pages rebuilt by scripts**: the paragraphs inside multi-column containers are laid out on the layout threads like the rest of the page (columns are still balanced from one layout of the content); an element whose font is its parent's no longer looks its font up, and the per-pass font table is a short list; the layout thread's temporary memory is kept from one pass to the next as intended (it was not). A page rebuilding 10 000 nodes a frame in six columns: a full layout pass 5.9 -> 3.5 ms, the frame's wait on layout 8.1 -> 5.3 ms. The numbers: `docs/performance.md`.
