**Odin JavaScript front-end** (`engine/frontend`) : a from-scratch ECMAScript front-end in Odin that compiles source to QuickJS-ng 0.17 bytecode (`BC_VERSION 28`), the E1 half of the Odin JS engine replacing the C compiler. Full 2025 lexer (Unicode identifiers with `\u` escapes, numeric separators, BigInt, templates, regexp literals, Annex B HTML comments, hashbang, private names), a recursive-descent parser for scripts and modules (functions, arrows, classes, destructuring, optional chaining, `??`/`??=`, `import`/`export`/`import()`/`import.meta`, ASI, strict mode, early errors), scope analysis, a bytecode emitter with short-opcode selection and a QuickJS-faithful stack-size pass, and a `JS_WriteObject` serializer (atom table, function tag, vardefs, closure vars, constant pool, LEB128) that is byte-compatible with the C engine. The AST is Odin tagged unions on an arena; everything is allocator-injected and builds for Windows, Linux and freestanding wasm32. Reuses the `numconv`, `unicode`, `regexp` and `bigint` leaf packages. A `judge` tool parses/compiles/dumps/fuzzes a corpus and emits the byte stream for differential comparison against QuickJS.
