**Odin JavaScript front-end** (`engine/frontend`): the E1 half of the Odin JS engine compiles ECMAScript scripts and modules to QuickJS-ng 0.17 bytecode (`BC_VERSION 28`) that is byte-for-byte identical to the C engine's `JS_WriteObject` output: 100 % of the 19 006 compiled test262 `language/` files, 99.99 % of the whole test262 tree, and the same syntax verdict on all 4 452 negative `language/` tests. It follows QuickJS's single-pass parse-and-emit compiler (whose byte order an AST pipeline cannot reproduce), then `resolve_variables`, `resolve_labels` with its peephole rules, `compute_stack_size` and the serializer, written in Odin with a tagged-union `JS_Value`, allocator injection and no libc, and builds for Windows, Linux and freestanding wasm32. Regexp literals compile to libregexp bytecode (`lre_compile` port, Unicode properties included), compilation speed matches QuickJS, and a stack budget turns runaway nesting into a "stack overflow" error instead of a crash. The `judge` tool emits, decodes, batch-compares, profiles and fuzzes against a QuickJS oracle.
