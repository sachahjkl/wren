Signed updates (Windows). A release now carries `update-windows-x64.json`, a manifest (version, file, length, SHA-256) signed with a key of its own (not the licence key), and `.json.sig`. About Wren has an "Updates" section: "Check for updates" asks GitHub, then fetches the manifest and checks its signature, platform, announced version and that it is newer; "Install the update" (also the command "Install the update") downloads the program, compares its length and SHA-256 with the signed ones, writes it beside the program, reads it back, and only then swaps it in, putting the old one back on failure. Nothing is installed without the button. Development and labelled builds, and Linux, only check. `wrentool update keygen|pubkey|manifest|sign|verify` makes and checks the files; `wrentool package -RequireUpdateManifest` is used by the release workflow (secret `WREN_UPDATE_SIGNING_KEY`).
