**Messages, dialogs and menus follow the toolkit's new API**: every message of the browser (a failed save, an update found, a Vault notice, the full-screen hint) now goes where the Messages setting (`general.messages`) says, a system notification by default, and a failure is always said. Dialogs open centred in the window. Typing in the main menu, a folder of the bookmarks bar, the Delete menu of the history, a download's menu and the menus of the developer tools now searches their items.
