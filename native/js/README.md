# native/js: the JavaScript glue

JavaScript runs inside WebAssembly like everything else. The engine is Odin (`src/engine`, see `docs/engine/`): a front-end
that compiles source to QuickJS-ng 0.17 bytecode, the interpreter `jsrt` (with a loop JIT), and `jscapi`, which gives it the
QuickJS C API. This folder is the *glue* written against that API: the web platform's objects, as native functions wired
to the browser's `wr_*` imports. All of it is Odin; no C of ours is compiled.

```
native/js/
  odin/             package odin_glue: the domains (one file per area: dom_*, web_*, load*, events, shadow, frames, ...)
    bindings_gen.odin   GENERATED by src/tools/bindgen (-emit:glue) from webref + api/*.widl: trampolines (wjg_*),
                        dictionaries (wjd_*), member and interface tables, wj_install_bindings
    wj/             package wj: the helper layer every domain imports (types, conversions, strings, errors, promises,
                    the engine's mirrored structs, the QuickJS-API aliases of backend_jsrt.odin, the generated wr_imports.odin)
    jsb/            package jsb: members bound to the shared API declarations by comptime bridges (docs/js/odin-abi.md)
    idb/            the IndexedDB model
    qjs_realm.odin  wj_preinit / wj_realm_start: the realm's life cycle and the exports the host calls
    jit.odin        wj_jit_configure / wj_jit_stat: the loop JIT seen from the browser
  odin_abi/         the shared API declarations (api_decl) the bridges read
  odin_gen/         the interface table of the generated bindings, for the host (src/page/js_interfaces_generated.odin)
  webref/           the Web IDL files (webref) the bindings are generated from
  licenses/         the licences of what is linked into the module (wasi-libc, musl, QuickJS-ng's, webref)
```

Built by `tools/build_js.ps1` (called by `build.bat`): the glue and the engine become one wasm32 object (`odin build
-build-mode:obj -target:freestanding_wasm32`), linked with wasi-libc by the pinned zig's `wasm-ld`, then pre-initialized
under Wasmtime (`src/tools/jsengine`: interfaces, prototypes and preludes built once, stored in the memory image the
browser embeds). The script does nothing when its inputs are unchanged.
