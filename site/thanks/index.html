Registering it

Open about:wren in Wren (menu, About Wren), paste the key into the box and press Register. Or drop the .wrenlicense file you just downloaded onto the Wren window.

Open the registration page in Wren

The button opens about:wren in Wren itself, whatever your default browser is. If nothing happens, open about:wren in Wren by hand.

The same key is sent to the e-mail address you gave at the checkout, with the file attached. Keep it: it covers every version of Wren, the updates after the beta included, on every computer you use. During the beta it unlocks nothing. Wren checks it on your computer, without any network access.

A problem with your licence? We are here.

No key, a key that is refused, a wrong name: write to us on GitHub with your order number (never the key itself) and we will sort it out.
