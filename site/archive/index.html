Every released version of Wren, newest first. Each one has its notes and the changes it brings.

0.4.0 - 2026-10-27

A text engine of its own, accessibility for screen readers, a readable configuration page, a list of search engines, pinned tabs and tab groups, several windows each on its own, and more of the web platform.

Release notes · Download

0.3.0 - 2026-10-21

A JavaScript JIT that produces WebAssembly, iframes, a browser that never waits for a busy page, an HTTP cache, passkeys, history as a tree, a command palette, and memory given back when idle.

Release notes · Download

0.2.1 - 2026-10-20

A fix for a crash about three seconds after start when the pointer was over the window.

Releases

0.2.0 - 2026-10-20

JavaScript, without giving up the one rule: WebAssembly is still the only execution engine. QuickJS-ng compiled to a Wasm module, bindings generated from the specifications' Web IDL, Shadow DOM, and the conformance suites in every run.

Release notes

0.1.0 - 2026-10-19

The first public build: WebAssembly is the only execution engine, the web APIs are Wasm imports generated from one description, and pages written in Wasm draw on a retained GPU compositor.
