Wren demos and tests

Every page that comes with the browser, by theme, with what it shows. The pages marked test server load from testserver.exe (http://127.0.0.1:8765/): start it first (demo.bat in the release, build\testserver.exe from the repository). The same list is built into the browser: about:demos.

CSS engine

Style engine

Selectors and the cascade, @layer, custom properties, :hover on cards, ::before, :nth-child lists, a linked sheet with @import, and an @media rule below 600 px.

Modern CSS

What sites write today: a variable WOFF2 web font, Color 4 and 5 (oklch, relative colors, color-mix), container queries, @property animations, :has() and revert-layer, @supports, math functions and units, <details>. Each section says what to expect.

Transitions and animations

CSS only: hover transitions that reverse halfway, endless keyframe animations (spin, pulse, alternate, steps), nested counters(), quotes by depth, gradients, and a web font with font-display: swap. style.animations.mode turns motion down.

Cursors

Every value of cursor in a grid (Windows' own cursors, and those it lacks drawn in the same style), images as cursors (PNG and SVG with their hotspot, image-set(), fallbacks of an image too large or missing), cursor: none, and what auto shows over text, links, fields, contenteditable, user-select: none and scroll bars.

Color schemestest server

A dark theme chosen by prefers-color-scheme from stylesheets in <noscript>, color-scheme, system colors (CanvasText, LinkText, GrayText), light-dark() and form controls in both schemes. Its stylesheets come from the server.

Layout

Layout engine

Flexbox, floats and clearance, positioning and stacking order, tables, lists, overflow and scroll boxes, borders, preformatted text.

CSS Grid

Named areas, repeat(auto-fill, minmax()) galleries, dense packing, alignment, nested grids with positioned boxes, and subgrid rows shared by cards.

Presentational HTML

Old attributes mapped to CSS as the HTML Standard says: <center> and align moving narrower blocks, tables with cellpadding, border, bgcolor, valign, <font>, list types, <hr size noshade>, floated images with hspace, and an image whose square width / height attributes give way to its own ratio under height: auto.

Rendering and effects

CSS effects

filter (blur, drop-shadow, color functions), backdrop-filter glass, every mix-blend-mode, animated clip-path shapes and shadows, drawn on the GPU; unchanged results are kept from frame to frame.

Masks, clipped text, legends, color glyphs

mask-image (gradients, luminance, mask-composite, repetition, under opacity), icons drawn as masks, background-clip: text, fieldset legends on the border, rounded images, scrollbar-color, and COLR v1, sbix, SVG and emoji color glyphs.

Gradients and shadows

Linear, radial, conic and repeating gradients, interpolation color spaces, background layers (size, position, repeat, origin, clip) and box-shadow.

Canvas 2D

getContext("2d") drawn in software: antialiased paths and strokes (caps, joins, dashes), gradients, patterns, clips, shadows, filter, compositing operators, text from glyph outlines, ImageData, drawImage, ImageBitmap, toDataURL and a requestAnimationFrame animation that uploads one texture per frame.

Transforms

Rotated text and blocks, nested rounded clips with a rotated one inside, a form turned by 10 degrees whose clicks land on the right character, group opacity, a transformed scroll box, and 500 cards turning forever over 300 static paragraphs.

3D transforms

Real perspective: perspective and perspective-origin, rotateX/Y, translateZ, preserve-3d (a turning cube with six translucent faces sorted by depth, a carousel on a ring), a card that flips over with backface-visibility: hidden, and text on a tilted plane that is hit where it is drawn. Each 3D element is rasterized once into a layer the GPU projects; tilting it again costs one matrix.

Text

Text: fallback, shaping, bidi

Per-character font fallback, color emoji, ligatures, kerning and OpenType features, complex scripts, bidirectional text, unicode-range (digits from another font), spacing and justification (the page is in French).

Text metrics and vertical alignment

Where text sits in its line, as in Chrome and Edge: line-height: normal from each font's rounded ascent, descent and line gap, numeric line heights, every vertical-align for spans and inline blocks, mixed fonts and emoji fallback, Wikipedia's inline-flex tabs with min-height, buttons, form controls on the baseline and table cells (the page is in French).

Web fonts: font-display after the first painttest server

Text added after the first paint whose web font arrives 3 s later: with font-display: block it stays invisible during the block period instead of showing the fallback font, with swap the fallback shows at once and is swapped (the font is served slowly by the test server).

Selection, menus and keyboard

Double and triple click, drag selection across columns, ::selection, user-select, a rotated selectable span, context menus, focus rings, find in page (Ctrl+F) and a scroll box.

Images

Imagestest server

PNG, BMP, JPEG with EXIF orientation, ICO, TIFF, animated GIF, object-fit, srcset and <picture>, broken, missing, truncated and decompression-bomb files, cross-origin images, CSS backgrounds and lazy loading, all counted by the server.

Built-in image decoderstest server

AVIF (8 and 10 bits, alpha, 4:4:4, rotation and mirroring, Display P3, animation), WebP (lossy, lossless, alpha, animation), Adobe RGB JPEG, <picture> and Accept negotiation, SVG as an image and as a background, inline <svg>.

Video and audiotest server

<video> and <audio>: H.264 + AAC (MP4) and AV1 + Opus (WebM) through the system's decoders, on the GPU where possible, the picture drawn with border-radius, object-fit and a transform, exact colors, events, canPlayType, seeking, rate and volume, and Media Source Extensions appending a fragmented MP4 piece by piece.

External link iconstest server

An SVG icon in the ::after background of external links, and filter: invert() to show it on a dark page.

Fullscreen APItest server

requestFullscreen() on a video, a styled card (:fullscreen) and two frames (one refused by allow="fullscreen 'none'"): the window fills the screen without tabs, address bar or status bar; Esc or F11 leave; fullscreenchange and fullscreenerror are logged. A click is needed, as in other browsers.

WebAssembly APIs and workers

A page with no JavaScript

Real HTML whose behaviour is a WebAssembly module (counter.wasm, written in Odin): buttons, a ticking timer, DOM updates, and a relative link.

Page lifetime

Reached from the counter page: navigating closed the previous page, and freed its Wasm instance, its timer and its DOM with it.

Form controlstest server

Text, email, number, date, range, color, select and file controls, validation pseudo-classes (:user-invalid, :out-of-range), a Wasm module that reads, fills and validates the form, and a multipart POST to the server.

JavaScript

Frames: nested documents

<iframe>s with documents of their own (their origin, scripts and JavaScript engine instance): same-origin and cross-origin frames, srcdoc, sandbox, postMessage, a form and links aimed at a named frame.

JavaScript in WebAssembly

Plain HTML and JavaScript run by QuickJS-ng compiled to WebAssembly, one sandboxed instance per page: a click listener, nodes built with createElement, the bindings' prototype chain (generated from the specifications' Web IDL), ES2023 features and microtasks. Off with javascript.enabled.

DOM from JavaScript

A to-do list driven by classList and dataset, a MutationObserver log of the changes, a box resized from script and measured with getBoundingClientRect, and a form read through elements and querySelectorAll into a table.

Shadow DOM

Declarative shadow roots (<template shadowrootmode>) that render with JavaScript off: encapsulated styles, :host, ::slotted(), ::part() themed from the document, named and nested slots. From script: a tabs element with manual slot assignment and delegatesFocus, toggles sharing one constructed stylesheet through adoptedStyleSheets with a :state(), and a closed shadow tree whose events are retargeted to its host.

Script loadingtest server

HTML's script processing: a head script before <body> exists, a deferred external script, a module with an import map, document.write, <noscript>, an onclick attribute, setInterval, and the order of DOMContentLoaded and load.

Web APIs from JavaScripttest server

One row per API, run in the page's realm: fetch and response streams, XMLHttpRequest, AbortSignal.timeout, URL, TextEncoder, crypto.subtle, localStorage, history.pushState, FileReader, structuredClone, MessageChannel, WebSocket and EventSource.

Network and security

Content blocker: ads and trackerstest server

A page with simulated ads: a script, an image, a frame and a fetch from a third-party host, an .ad-banner element and an anti-blocker check. With the content blocker on (and the filters of build\tp1-style My filters), the requests are blocked and the banner is hidden before the first paint.

Content blocker: ad frametest server

The frame that blocker/ads.html embeds from a third-party host: a red box, collapsed when the blocker stops it.

Content blocker: scriptlets on the DOMtest server

remove-attr, remove-class, set-attr, remove-node-text, replace-node-text (also in an inline script before it runs), href-sanitizer, click-element and set-cookie, done natively on the document by the blocker with the filters of the blockertest profile.

Content blocker: scriptlets on the APItest server

set-constant, abort-on-property-read / write, timers, listeners, JSON.parse, fetch, XMLHttpRequest, eval and window.open hooked natively by the engine (blocker.hooks.native).

Content blocker: $replace on a documenttest server

A page whose own text a `$replace= filter rewrites before the parser reads it.

Content blocker: a YouTube watch pagetest server

The shape of a watch page: the player data in an inline literal and the answers of /youtubei/v1/player to XHR and fetch; the ad data in them (adPlacements, adSlots, playerAds) is removed before the page reads it.

Content blocker: rewritten responsestest server

A JSON answer of fetch and XMLHttpRequest and the JSON literal in this page's own markup pruned by the loader before the page reads them.

Content blocker: many blocked requeststest server

Starts 130 image requests (?n= sets the number) to a third-party host that the blocker stops: the badge of the shield counts them (99+ above ninety-nine).

Content blocker: blocked script in the headtest server

A script in the head that the blocker stops: the page must paint at once instead of waiting for it.

Content-Security-Policytest server

The counter page served with a policy that allows scripts only from unreachable hosts: its Wasm module is blocked, and the violation is reported.

Cookies and redirectstest server

Sets a cookie, then redirects to the counter page: the cookie and the redirect show in the page information of the address bar.

Developer tools: sockets, streams, workers, mediatest server

The page the developer tools' Network tab is shown with (tools\perf.ps1 -Only dt_network_idle): a WebSocket echo with a subprotocol, a Server-Sent Events stream, a worker that fetches, images, a web font, a video and fetches. Open the panel (F12) on Network and choose a request: Messages, Preview, the speed profiles.

Performance and stress

Content blocker: a page that keeps changingtest server

Thousands of text nodes and more arriving every few milliseconds: what the blocker's DOM operations cost on a busy page (tools\blocker_js.ps1).

Content blocker: cost of the API hookstest server

Per-call cost of a timer, JSON.parse and a defined property with the blocker's hooks (WREN_HOOKBENCH=1 with blockertest).

Mutation every frame

A module builds about 10 000 elements, then changes one span's text every 16 ms: only that paragraph is laid out again.

Class toggled every frame

A class toggled every 16 ms on a section among 10 000 elements: only what its rules reach is restyled and laid out again.

Video benchmarktest server

The page of the profiler's video scenarios (tools\perf.ps1 -Only video_idle,video_play,video_mse): ?mode=idle a paused video, play a looping one, mse the same through Media Source Extensions, none the page alone. A paused video draws no frame; a playing one one per picture.

Player simulatortest server

What a YouTube watch page costs, without the network (tools\perf.ps1 -Only yt_h264_1080p60,yt_av1_1080p30,yt_short): a player with the state classes and bare :has() rules the real one toggles, a progress bar moved on every animation frame, MSE with separate audio and video buffers and ~4 000 elements around it. Needs the 1080p files of tools\gen_perf_media.ps1.
