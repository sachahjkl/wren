Presentational HTML

Old attributes such as align, bgcolor, cellpadding, <font> and an image's width / height are mapped to CSS as the HTML Standard's rendering section says: author styles of the lowest priority, which any rule of the page overrides (preference style.presentational_hints.enabled).

<center> and a table

25%centered, nowrapright
<font size=+1>

The table is centered by <center> (text-align: -webkit-center), cells get cellpadding, the bordered table's cells an inset 1px border.

align on blocks

align=right
align=center
text-align only

A narrower block inside align=center moves; with CSS text-align: center only its text would.

An image's width and height

The attributes say 200 x 200; the page's height: auto keeps the photo's own ratio once it is decoded (320 x 200: the image is not square). Before that, the attributes' ratio holds its place.
