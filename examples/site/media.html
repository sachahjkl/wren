Built-in image decoders

Links to webassembly.org and resvg get an external-link icon (an SVG background image in a ::after), as on webassembly.org.

AVIF (rav1d): 8 bits + alpha, 10 bits + alpha, 4:4:4, irot, imir, irot + imir, Display P3, animation

WebP (image-webp): lossy, lossless + alpha, lossy + alpha, animation

<picture>: AVIF first, then WebP, then PNG; content negotiation on Accept

SVG as an image: natural size, scaled 3x (rasterised again), viewBox only (as wide as its container), CSS backgrounds

Inline <svg>: currentColor, font, sprite with <use>
