# Wren 0.6.2

**Wren 0.6.2 links its JavaScript engine with no Zig and no C library, and repairs its documentation site.**

This is still a beta, under development, and Windows-only.

### Highlights

- **No Zig, no C library.** The engine module is linked by the `wasm-ld` that ships with Odin. The heap, the string functions, `strtod`, `snprintf` and `ldexp` are Odin (`native/js/odin/wj/libc.odin`), `exp` is fdlibm's, and `sin`, `cos` and `pow` come from the host. Only Lexbor remains as external C.
- **The documentation site.** Its pages use links relative to the site's root, so they have their style, logo and search under `/wren/`. Code wraps instead of overflowing. The changelog page and the version on the home page follow the releases.
- **The pictures of the home page.** Four pictures of one window with four tabs, as the clickable zones expect, and new captures of every page from a current build.
