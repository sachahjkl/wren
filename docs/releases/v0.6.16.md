# Wren 0.6.16

**Wren 0.6.16 loads pages made of ES modules faster: GitHub, and most modern sites.**

This is still a beta, under development, and Windows-only.

### Highlights

- **Each module is compiled once.** The engine compiled every ES module twice: when it arrived, to learn what it imports, and again when the graph ran, because the first was not kept. It is now kept.
- **Modules are in the bytecode cache.** Compiled modules go to the profile's cache, as classic scripts already did, so a module seen before is read instead of parsed. On the repository page of Wren on GitHub (about 130 modules) the page is stable after 4.0 s instead of 7.8 s on a visit that finds them in the cache, and the longest stall between two frames goes from 1.9 s to 0.7 s. The first visit gains about a second.
