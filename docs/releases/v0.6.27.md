# Wren 0.6.27

**Wren 0.6.27 fixes links that all showed their hover style together, and follows the standards more closely for names, international domain names and forms.**

This is still a beta, under development.

### Highlights

- **Hovering one link no longer restyles its look-alikes**: links that share a style (a site's nav, the start page's
  Configuration, History and Content blocker links) each show their hover state alone again.
- **International domain names** follow the URL Standard: `xn--` hosts are only lowercased, labels starting with a
  combining mark or with a misplaced zero-width joiner are refused.
- **Names as scripts give them**: `createElementNS` and `setAttributeNS` keep their case, namespace selectors
  (`*|div`, `|div`) work, and an iframe answered as XML is shown as an XML document.
- **Two forms sent at once to two frames** both arrive (the second used to cancel the first).
- **A `setTimeout(0)` set by a script runs after the tasks that script queued**, as in other browsers.
- **XHR and FileReader text** honour a byte order mark.
- **Full style passes are faster again** (the page's color scheme read from its `<meta>` elements, subtrees weighed
  in one walk), and pages with columns build their display list on the layout threads.
