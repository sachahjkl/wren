# Wren 0.6.5

**Wren 0.6.5 makes drags work in frames, and sends the pointer's events where other browsers do.**

This is still a beta, under development, and Windows-only.

### Highlights

- **Drags in frames.** An iframe's scripts now get `mousemove` / `pointermove` and the boundary events, and a document in which a button was pressed keeps the moves while it is held. jQuery UI's demos (draggable, droppable, sortable, resizable, selectable, slider) work in their frames.
- **The pointer over an empty part of a page** is over the root element: `mousedown`, `mousemove`, `mouseup` and `click` reach it, as do `:hover`. A script that waited for a `mouseup` over the background no longer believes the button is still down.
- **Order of the pointer's events.** The move comes before the press or release that follows it in the same frame.
- **Autoscroll** (middle click): the speed grows geometrically with the distance from the anchor, `max * (2^(x/D) - 1) / (2^(F/D) - 1)`, and doubles every 80 px by default (`browser.scroll.autoscroll.doubling_distance`).
- **Images in shrink-to-fit boxes** (blog.jquery.com): an image with a percentage `max-width` no longer makes its inline-block link as wide as itself.
