# Wren 0.6.29

**Wren 0.6.29 can install its own updates, signed and checked, and brings devtools, JIT and compatibility work.**

This is still a beta, under development.

### Highlights

- **Signed updates (Windows)**: a release carries a manifest signed with a key of its own. About Wren checks for a newer release and, when you press "Install the update", downloads the program, compares its length and SHA-256 with the signed ones, and swaps it in with a way back. Nothing is installed without the button. The channel (address, files, key, signature required) is configurable: see [docs/updates.md](../updates.md).
- **Developer tools**: find in the panels, a console drawer, a colour picker, style values.
- **Faster scripts**: the JIT compiles whole functions, calls, objects, strings and DOM getters.
- **Compatibility**: SVG `foreignObject`, CSS module scripts, subresource integrity, script preparation, CSSOM rules and `innerText`, among many fixes (see the list below).
- **Help**: the licence help button opens a GitHub issue form with your order number filled in.
