# Wren 0.6.10

**Wren 0.6.10 redesigns the start page.**

This is still a beta, under development, and Windows-only.

### Highlights

- **A quieter start page.** The logo, the title and the tagline stay; the large cards are replaced by a row of thin links with a line icon each (Configuration, History, Content blocker, Demos & tests), and a link with a small coloured painting turns the painting start page on.
- **The painting page's shortcuts** are the same four links, frameless and faint over the picture, instead of dark pills.
