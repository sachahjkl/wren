# Wren 0.11.0

**Wren 0.11.0 has a new look, and the settings now hold What's new, the installation, the updates and diagnostics.**

This is still a beta, under development.

### Highlights

- **A lighter default look, with tabs like Chrome's**: Wren starts in the gradient finish. The current tab joins the
  toolbar in its colour. Pages follow Wren's light or dark look when the color scheme is automatic.
- **What's new**: about:settings shows Wren's changelog, with a search and a filter by kind of change. The first start
  of a new version says so, and a click opens the page.
- **Installation and updates in the settings**: install, repair, upgrade or uninstall Wren from about:settings. On
  Windows, the System page shows the update state, with Check now, Install and Restart now. Once Wren is installed, the
  same page sets the applications menu entry and the start with the session.
- **Diagnostics**: a page with the graphics adapter, the window and the last frames' times, with a Copy button for a
  report.
- **One spacing across the interface**: pages, panels, dialogs and bars use the same gaps for the same things.
- **The developer tools' Network detail folds to a rail** when the panel is too narrow for the request list, and opens
  again when it is wide.
- **The Vault on Windows**: no empty console window beside it any more, and when a passkey cannot log in, the message
  names the Windows version that is needed.

### Upgrading

- A profile that answered the installation offer before is asked once more: the answer is now kept with your
  preferences.
- about:wren no longer has an Updates section, and the `browser.update.*` settings are gone: updates are in
  about:settings, System.
- The setting `browser.desktop_integration.start_menu` is gone: the System page's "In the applications menu" replaces it.
- A finish you chose before is kept; only a new profile starts in the gradient finish.
