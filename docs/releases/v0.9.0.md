# Wren 0.9.0

**Wren 0.9.0 lets you set your own keys for any command, and shows your license as a card in the settings.**

This is still a beta, under development.

### Highlights

- **Your own keys and aliases**: in the command palette, Ctrl+Enter on a command records a key for it (or two in a
  row), and Alt+Enter makes what you typed its alias. Your key wins over the command's own, and the menus, the tooltips
  and the shortcut sheet show it.
- **The license in the settings**: about:settings has a License page with the license card, the key field, Choose a
  file and Remove.
- **One folder for Froment Software's programs**: the profile is in `FromentSoftware\Wren`, next to the other programs
  of the same vendor.
- **The JavaScript engine is shared** with the other programs of the family. Nothing changes in what pages can do.

### Upgrading

- At its first start, Wren moves your profile from `%APPDATA%\Wren` (`~/.config/Wren` on Linux) to
  `%APPDATA%\FromentSoftware\Wren`, with your settings, history and Vault. If the move fails, Wren keeps the old folder
  and tries again at the next start.
- Ctrl+Enter on a command of the palette now sets a key. To open a built-in page in a new tab, use the command
  "Open a built-in page in a new tab".
