# Wren 0.6.23

**Wren 0.6.23 plays Web Audio, and vscode.dev, tldraw and reddit work.**

This is still a beta, under development.

### Highlights

- **Web Audio.** `AudioContext`, `OfflineAudioContext`, the usual nodes, `decodeAudioData` and `ScriptProcessorNode`, on Windows and Linux, following the autoplay policy. The web-platform-tests of `webaudio` go from 24 % to 92 %. `AudioWorklet` is not there yet.
- **vscode.dev works**: its compile no longer runs into a time limit, large scripts compile about 3.6 times faster, a service worker's opaque answer reaches the page, and a `<meta>` policy no longer applies to code before it.
- **reddit works**: a form submitted while the page loads goes through, a hang that grew to 22 GB of memory is gone, and `getComputedStyle` answers for shorthands.
- **tldraw's icons show**: an SVG image's fragment now makes `:target` match.
- **Regular expressions search faster**: Octane's regexp from 127 to about 165.
- **A same-origin frame gives `navigator`, `screen` and `crypto`**, which scripts often take from a frame they just made.
