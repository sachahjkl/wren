# Wren 0.15.1

**Wren 0.15.1 updates `gui_toolkit` to 0.370.2 (tighter panel tabs, per-tab close cross and middle-click on stacked views, deduplicated command palette recents) and simplifies descriptions and headers.**

This is still a beta, under development.

### Highlights

- **Tighter panel tabs and stacked view close**: panel and view tabs use tighter horizontal padding, and stacked view tabs carry a per-tab close cross and close on middle click.
- **Deduplicated command palette recents**: items shown under Recent in the command palette are no longer repeated underneath.
- **Cleaner About and start page headers**: the About dialog, `about:wren`, and `about:home` omit the subtitle under the Wren title, while external metadata (desktop entry, flake, website, and packages) use "Web browser".
