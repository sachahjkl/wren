# Wren 0.7.4

**Wren 0.7.4 puts the tabs in a tree, keeps bookmarks, and opens private windows.**

This is still a beta, under development.

### Highlights

- **Tabs as a tree**: a tab a page opens goes under the page's tab in the sidebar, with guide lines; a subtree folds away, and a tab dragged sideways goes deeper or less deep.
- **Bookmarks**: the star of the address bar (Ctrl+D), about:bookmarks (Ctrl+Shift+O) with folders, import and export of the HTML file every browser reads, and bookmarks among the address bar's suggestions.
- **Private browsing** (Ctrl+Shift+N): a Wren of its own in a temporary profile, removed when it ends.
- **A settings page** (about:settings), the toolkit's themes with the system's light or dark, and a machined style.
- **Notifications**: the Notifications API, and the end of a download when Wren is not in front.
- **Setup** works on a thread of its own and follows the disk while it is open.
- **Partial redraw**: a frame draws again only what changed, the page included.
