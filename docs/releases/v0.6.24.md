# Wren 0.6.24

**Wren 0.6.24 draws WebGL and positions with CSS anchors: Three.js and MapLibre run.**

This is still a beta, under development.

### Highlights

- **WebGL and WebGL 2**, through wgpu and naga, with a device and a thread for each context. Three.js examples and MapLibre maps run: a simple scene at 60 frames a second, a heavy one at 20 to 30, on a good GPU. A machine with no adapter gets `null`, as a page expects. Transform feedback and real queries are not there yet, nor WebGL in workers. There is no separate GPU process: a crash inside a driver takes the browser down.
- **CSS anchor positioning**: `anchor()`, `anchor-size()`, `position-area`, `position-try-fallbacks`, `@position-try`, `position-visibility`, implicit anchors of popovers. The web-platform-tests of the folder go from 13.7 % to 85 %. No writing modes or anchor names across shadow trees.
- **A compiled loop's return no longer leaks stack depth**: pages could end in a false "Maximum call stack".
- **`TypedArray.prototype.set`** no longer traps on large arrays.
- **Scroll containers count the end margins of their children** as scrollable overflow, as other browsers do: `scrollHeight` may grow.
