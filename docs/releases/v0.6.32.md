# Wren 0.6.32

**Wren 0.6.32 makes the browser's own behaviour steadier: what happens to a press, a key, a navigation and a loading page is now decided in one place each, which removes a long list of bugs.**

This is still a beta, under development.

### Highlights

- **Navigation**: Escape before a page answers no longer leaves a dead tab, a document unloads once, and a page you have left no longer writes into the next page's history entry.
- **Mouse**: one owner for the pressed button. A press no longer survives a navigation or a tab switch, Escape during a drag really ends it, and a scroll bar's arrow held across a tab switch no longer keeps the browser busy.
- **Keyboard and address bar**: letters no longer go to a frame of a hidden tab, what you are typing in the address bar stays, Ctrl+L works in full screen with the bars hidden.
- **Busy pages**: input held under a long script no longer lands on another tab or window, and every window keeps its picture of the page, so a page does not show its background alone.
- **Page loads**: deferred scripts and modules wait for the first paint, and cnn.com loads about a fifth faster with less style work.
- **Crash recovery**: its files are written again when another program holds them open, as a virus scanner can.
