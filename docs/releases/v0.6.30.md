# Wren 0.6.30

**Wren 0.6.30 fixes a crash on pages with radio buttons, keeps animations and scrolling alive under busy scripts, and puts a new tab's keyboard in the address bar.**

This is still a beta, under development.

### Highlights

- **A crash fixed**: styling a page with radio buttons on several threads could free a list twice and abort Wren (seen on Linux on Wikipedia). The style threads now only read the forms' state, settled before they start.
- **A busy page keeps moving**: while a page's script runs a long task, CSS animations of transform and opacity go on, scroll boxes follow the wheel and their scroll bar, and the caret keeps blinking.
- **New tab**: Ctrl+T puts the keyboard in the address bar; the list of pages visited opens for a click or a letter, not by itself. With the art new tab on, the first painting is fetched a moment after the start.
- **Compatibility**: CSS Nesting's nested declarations, `document.write`'s insertion point, promise rejections and muted errors as HTML reports them, `toggle` on `<details>`, clicks dispatched by scripts.
