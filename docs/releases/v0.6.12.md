# Wren 0.6.12

**Wren 0.6.12 slows middle-click autoscroll down by half and brings the first painting sooner.**

This is still a beta, under development, and Windows-only.

### Highlights

- **Middle-click autoscroll is half as fast**: the top speed is 15000 px/s (was 30000), reached at the same distance; every speed in between is halved. `browser.scroll.autoscroll.max_speed` sets it.
- **The first painting comes sooner.** With nothing downloaded yet, the smallest of the listed files goes first, and a file larger than `browser.newtab.art.max_image_bytes` is no longer downloaded just to fail. The page reads "Loading a painting…" instead of "No painting could be loaded yet".

### Changed

- The icons of the start page's search box (the lens and the arrow) are bigger.
