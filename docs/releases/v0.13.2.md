# Wren 0.13.2

**Wren 0.13.2 fixes Vault PIN unlock sessions, Linux 2D canvas colors, CSSOM rule splitting on Tailwind v4 sites, DevTools checkbox contrast, `navigator.platform` defaults, and sidebar chrome borders and tree elbows.**

This is still a beta, under development.

### Highlights

- **Vault PIN unlock (`wren-vault` 0.5.1)**: unlocking the Vault with a PIN keeps the session open through the sync that follows instead of prompting for the master password again, and saves the helper's PIN flag to the profile account file on startup.
- **2D canvas colors on Linux**: software 2D canvases keep exact sRGB colors on WGPU instead of appearing washed out or semi-transparent.
- **Stylesheets with escaped quotes in selectors**: reading `sheet.cssRules` on stylesheets containing escaped quotes (such as Tailwind v4 arbitrary-value classes on x.com) keeps all subsequent rules intact across style rebuilds.
- **Readable checkboxes and accent badges**: DevTools uses WCAG AA solid-accent ink in every light and dark theme with a crisp 12 px vector checkmark in Styles, paired with `gui_toolkit` 0.358.1 checkbox contrast and a deeper Ember Light accent.
- **Chrome hairline border and smooth tree-tab elbows**: the top toolbar and bookmarks bar draw a bottom hairline matching the vertical tab sidebar edge, and nested tree-tab connectors render as one smooth stroke without dark dots at joints.
- **OS-matched `navigator.platform` default**: `navigator.platform` defaults to `Linux x86_64` on Linux and `MacIntel` on macOS (keeping `Win32` on Windows), matching `User-Agent`.
