# Wren 0.6.1

**Wren 0.6.1 makes the Odin JavaScript engine lighter.** An empty realm takes 4.3 MiB of WebAssembly memory instead of 6.4, and is created in 1.3 ms instead of 2.3; a page with 650 KiB of script takes 23 MiB instead of 27, and 14 MiB once compiled, before it runs.

The compiler frees what a function's passes need as soon as its bytecode exists, and the Web IDL prototypes define their members the first time a script looks at them. The bytecode is unchanged: it is identical to QuickJS-ng's on the 19,006 files of test262's `language/` directory.
