# Wren 0.15.0

**Wren 0.15.0 scales its window buttons with the interface, adopts the shared About dialog with direct access to What's new, and updates docked panels and the debug window via `gui_toolkit` 0.370.1.**

This is still a beta, under development.

### Highlights

- **Window buttons follow the interface scale**: minimize, maximize, and close buttons scale with the UI zoom instead of staying at 100 %, keeping the system look at 100 % and aligning snap layouts.
- **Shared About Wren dialog**: choosing About Wren from the menu or command palette opens the shared About dialog with a primary in-app "What's new" button, version and diagnostics copy buttons, and links to the website, online release notes, `about:wren`, and `about:licenses` that open inside Wren.
- **Permanent compact header on docked panels**: docked DevTools and other lone panels always show a slim header bar with a drag grip, menu, and close button.
- **Debug window in every build**: press `Ctrl+Alt+Shift+D` to open the toolkit's debug window and Wren's own state panel in release builds too, with a dedicated drag grip and scrollable tabs.
- **Aligned theme grid and steadier menus**: incomplete last rows in the theme picker match the 3-column width, context submenus use a safe hover corridor and edge flip, and Alt menu mnemonics wait 150 ms before showing underlines.
