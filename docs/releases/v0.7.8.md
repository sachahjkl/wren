# Wren 0.7.8

**Wren 0.7.8 moves to gui_toolkit 0.180.3.**

This is still a beta, under development.

### Highlights

- **A second window never waits for the screen** on Wayland.
- **Segmented controls** in the machined style are a slot with a raised key.
- **The command palette** no longer stops on a search that keeps nothing.
