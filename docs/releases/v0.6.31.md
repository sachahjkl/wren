# Wren 0.6.31

**Wren 0.6.31 is much faster on heavy pages: first paint comes up to three times sooner, loads take about a third less time, and the first page after an install no longer waits for the JavaScript engine to compile.**

This is still a beta, under development. It also holds everything prepared for 0.6.30, which was never published.

### Highlights

- **First paint**: a web font on its way no longer holds the whole page back, and long scripts leave room for the first frame. Measured from a first load: cnn.com about 1.6 s down to 0.5 s, theverge.com 0.75 s to 0.45 s, bbc.com 1.1 s to about 0.2 s.
- **Loads**: a faster JavaScript engine and far fewer full style passes. cnn.com from about 6.3 s to 3.5 s; Wren is still 2 to 4 times slower than Edge on these heavy pages.
- **First page after an install or an update**: the engine's machine code now ships in the program, instead of being compiled on the first script. On cnn.com, first paint goes from 3.3 s to 0.6 s on a new profile, and from 17.7 s to 0.75 s on two cores. The program is about 22 MB larger for it.
- **Busy pages**: selection, scroll bars, the caret and CSS animations keep working while a script holds the page, and scripts can be interrupted inside the engine's own loops.
- **Fixes**: YouTube search finishes again, Ctrl+T gives the keyboard to the address bar, triple click selects reliably, scroll bars answer the pointer, and closing a background tab or zooming with the wheel no longer blinks.
