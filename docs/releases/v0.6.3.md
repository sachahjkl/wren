# Wren 0.6.3

**Wren 0.6.3 repairs tabs and scrolling, and lays out Bootstrap's documentation as the other browsers do.**

This is still a beta, under development, and Windows-only.

### Highlights

- **Tabs.** A middle click on a tab closes it again. A tab dragged onto another window's tabs shows where it would go: the carried window steps aside, the tabs make room and a faded copy of the tab stands in the gap.
- **Scrolling while a page is busy.** The page's scroll bar no longer jumps up and down while a script keeps the interface thread: it was drawn into the kept picture of the page and moved with it. The loading bar and the page held during a navigation are the same in every frame.
- **Bootstrap's documentation.** A grid item with a stated minimum no longer stretches the flexible tracks (the content column of its pages), `<meta http-equiv="refresh">` redirects work, and a script that writes a style it already has no longer restyles the page: its table of contents did it at every scroll event.
- **The tab sidebar.** A light line along its inner edge shows where the page begins, in both styles.
