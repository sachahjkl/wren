# Wren 0.7.9

**Wren 0.7.9 fixes what a static review of the whole code found, and moves to gui_toolkit 0.201.0.**

This is still a beta, under development.

### Highlights

- **Safer against hostile pages and servers**: a compressed response, a script that fills the DOM or arms timers in a
  loop, a nameless cookie posing as `__Host-`, and long selectors no longer exhaust memory or stall the browser.
- **Faster pages**: nested flex containers, large `innerHTML`, deep event paths, `Map` and `Set` caches, substrings and
  2D canvases without the GPU are many times faster.
- **The interface does less at rest**: the history, the session and the other profile files are written in the
  background, and a background tab draws only its own window.
- **A centred address bar** (`browser.address_bar.sizing_mode`), and a right click on the free space of the title bar
  opens the toolbar's menu.
- **Bookmarks move sooner** when you drag them along the bar.
