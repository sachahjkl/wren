# Wren 0.7.0

**Wren 0.7.0 runs on Linux as it does on Windows: it builds, installs, updates itself and starts on NixOS. Pages also load and run faster, and the JavaScript heap is smaller.**

This is still a beta, under development.

### Highlights

- **Linux**: `wrentool build` makes every variant on Linux. H.264 videos play, the windows carry the app id `wren`, the page fonts follow fontconfig, and a second start of a profile no longer takes the running Wren for a crash.
- **NixOS**: Setup makes the installed copy start by itself, without steam-run.
- **Faster pages**: script functions that never run cost almost nothing to load, garbage collection stops a page for far less time, and the style work is smaller when the DOM changes.
- **A smaller JavaScript heap**: an object takes 40 bytes, and the collector reads only what dies.
- **Text**: CSS Text Decoration 3 and 4 in full, highlight pseudo-elements as CSS Pseudo 4 paints them, and text fragments (`#:~:text=`).
- **The browser**: Ctrl+Shift+T reopens the previous session after a restart, a link's address shows over the page, and the frame rate is a choice in the View menu.
- **The documentation site**: a menu, a search and a breadcrumb, and tables that scroll sideways on a phone.
