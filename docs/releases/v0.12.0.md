# Wren 0.12.0

**Wren 0.12.0 cuts binary size and memory use, moves heavy I/O off the interface thread, and fixes DevTools docking, preference saving, WebAuthn prompts, and Wayland support.**

This is still a beta, under development.

### Highlights

- **Smaller binaries and lower memory use**: release builds compress the embedded JavaScript engine image, compact generated bindings, and pack Linux relocations. DOM nodes, styles, layout boxes, and compositor tables use compact layouts.
- **Smoother frames and off-thread I/O**: container queries, observers, and lazy-image checks skip unchanged frames. Downloads, Cache API writes, and user stylesheets run off the interface thread.
- **DevTools dock inside the viewport**: docked Developer Tools stay inside the page viewport. The tab bar, toolbar, sidebar, and status bar keep their full window span.
- **Preferences stay saved**: free-text fields in about:config (including `network.user_agent`) and about:settings commit on blur, tab switch, and exit. Preference changes write `prefs.txt` in the background immediately.
- **Themes carry their whole look, plus Old Head**: themes now set corner radii, selection ink, focus style, animations, font, and title-bar tab rows. Old Head joins the built-in themes in about:settings.
- **WebAuthn and Linux parity**: security-key PIN, touch, and account prompts wake the browser loop without freezing. Linux adds the `<input type="color">` popover, loopback `--remote-debugging-port`, per-monitor Wayland refresh rates, and Wayland tab drag-out.
- **Web compatibility and `PointerEvent.getCoalescedEvents()`**: drawing apps can read sub-frame pointer samples. Pages using Material UI (`CSS.px()`), legacy `-webkit-gradient()`, spaced inline text, and animated inline SVG strokes render cleanly.
- **File dialogs, menu filtering, and hardening**: file dialogs offer details, names, columns, and thumbnail card views, and menus filter as you type. File System Access, CDP origin checks, DevTools media previews, Wasm cache writes, and extension unpacking are hardened.
