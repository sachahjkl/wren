# Wren 0.6.14

**Wren 0.6.14 sends the downloads straight to a folder you choose.**

This is still a beta, under development, and Windows-only.

### Highlights

- **No Save dialog by default.** `browser.download.ask` is now off: a file goes at once to the download folder, under a name that is free (the Downloads folder of Windows unless you chose another).
- **The folder is yours to choose.** At the top of about:downloads, the folder in use with **Change…** (the folder picker of Windows) and **Default** (back to the Downloads folder of Windows), and a switch "Ask where to save each file" for those who prefer the Save dialog.
