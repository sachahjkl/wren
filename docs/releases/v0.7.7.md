# Wren 0.7.7

**Wren 0.7.7 moves to gui_toolkit 0.174.0.**

This is still a beta, under development.

### Highlights

- **Text fields have a menu**: a right click offers Undo, Cut, Copy, Paste and Select all.
- **Middle-click autoscroll** in the interface's scroll regions.
- **A second start of Wren brings the first one forward** on Wayland, with the token its launcher gave it.
- **"License"** is spelled with an s everywhere Wren shows it.
