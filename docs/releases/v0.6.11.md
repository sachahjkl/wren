# Wren 0.6.11

**Wren 0.6.11 adds a search box to the start page and suggests pages when the address bar gets the keyboard.**

This is still a beta, under development, and Windows-only.

### Highlights

- **A search box on the start page.** It does what the address bar does with the same text: words go to the default search engine (a keyword such as `@g cats` picks another), an address opens as it is. The small texts at the bottom of the page are gone; the version and "by Froment Software" stay.
- **Suggestions on focus.** A click in the address bar, Ctrl+L or a new tab lists the pages visited most and most lately before anything is typed. Nothing is chosen at first, so Enter still does what the field says. `browser.urlbar.top_sites` turns it off.

### Fixed

- A visited page no longer takes the title "New tab" (or an error page's title) in the history and in the suggestions.
