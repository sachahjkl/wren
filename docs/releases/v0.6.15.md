# Wren 0.6.15

**Wren 0.6.15 styles big pages several times faster.**

This is still a beta, under development, and Windows-only.

### Highlights

- **A style pass that really uses the threads.** On a page whose elements sit under one chain of containers (GitHub, most web apps), the work was shared level by level, so one thread did nearly all of it. It is now shared by weight. A full pass on the Wren repository page on GitHub goes from about 190 ms to 52 ms; its styles take 1.5 s instead of 3.6 s while it loads, and the 95th percentile of the gaps between two frames goes from 480 to 330 ms.
- **A way to measure a real site**: `tools\perf.ps1 -Only github_load,github_scroll` loads and scrolls the repository page with the profiler.
