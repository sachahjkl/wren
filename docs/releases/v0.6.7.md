# Wren 0.6.7

**Wren 0.6.7 updates its toolkit and corrects its README.**

This is still a beta, under development, and Windows-only.

### Highlights

- **gui_toolkit at its latest master**: a Linux window with its platform services, password fields, `fuzzy_score`, check boxes and switches that fit their mark and label.
- **The README** no longer opens with the toolkit's old description and describes the JavaScript engine as the one written in Odin.
