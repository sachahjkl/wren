# Wren 0.6.9

**Wren 0.6.9 puts the painting start page one click away, and fixes its first appearance.**

This is still a beta, under development, and Windows-only.

### Highlights

- **A switch on the pages themselves.** The start page has a card, "A painting on every new tab", that turns the painting start page on; the painting page has a "Plain start page" link that turns it off. No more digging in the settings. Only the address bar or a link of the start page itself can flip it: a web page cannot.
- **The first painting arrives in place.** The first new tab after turning the option on used to show "No painting could be loaded yet" for good; it now shows the first painting that is ready as soon as it is.
- **Discreet buttons.** "Another painting", "Open the record" and "Plain start page" are small, frameless text links, faint until the pointer is on them.
