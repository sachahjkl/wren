# Wren 0.13.1

**Wren 0.13.1 fixes concurrent WebAssembly module compilation starvation, toolbar layout jitter, `wren ctl wait stable` on animated pages, and cleared site-data reporting.**

This is still a beta, under development.

### Highlights

- **WebAssembly module compilation deduplication**: concurrent tabs and workers loading the same WebAssembly module share one compilation instead of compiling duplicate copies in parallel and starving worker startup.
- **Remote `wait stable` on animated pages**: `wren ctl wait stable` and `Wren.wait` complete once layout, style, and pending page updates settle instead of timing out on pages with continuous CSS or Web animations or playing media.
- **Cleared localStorage in site data and reset**: clearing site data or running `wren ctl reset` removes cleared origins from `about:sites` and remote stats immediately while background disk writes finish.
- **Toolbar layout stability**: fixes a 1-pixel horizontal jitter in the centred address bar and right toolbar group when trailing controls have fractional pixel widths.
