# Wren 0.6.13

**Wren 0.6.13 adds a download manager.**

This is still a beta, under development, and Windows-only.

### Highlights

- **A downloads button and its drop-down.** Once a download has run, a button joins the toolbar: a ring fills around its arrow as the files arrive, and the drop-down (it opens by itself when a download begins) lists the latest ones with a progress bar, the speed and the time left. The cross cancels, a click opens the file, the folder icon shows it in the file manager.
- **about:downloads (Ctrl+J).** Every download by day, with a search box. Per file: Open, Show in folder, Copy download link, Download again, Delete the file, Remove from the list; Try again for a failed one; Clear the list for all the finished ones.
- **A list that stays.** The finished downloads are kept across restarts (up to `browser.download.list_max`, 200 by default); a file moved or deleted since says so.
- **A progress bar that is good to look at**: it eases toward the real figure, with a gloss on its upper half and a light band travelling over it; a comet runs while the size is not announced.
