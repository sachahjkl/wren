# Wren 0.6.19

**Wren 0.6.19 stops GitHub's file list from running over its sidebar, and answers input a frame sooner.**

This is still a beta, under development, and Windows-only.

### Highlights

- **`table-layout: fixed` is honoured.** A table with a width and `table-layout: fixed` took its columns from the content, so a commit message that does not wrap widened the file list of a GitHub repository page over its sidebar. The columns now come from the `<col>` elements and the first row, and the automatic ones share what is left.
- **A frame less between input and screen**, from the latest `gui_toolkit`: on GitHub, with the pointer moving over the page, the time from an input to the refresh that shows it goes from 49.9 ms to 35.9 ms on average (60 Hz screen, same machine and page). The toolkit also gains a lazy column, `ui.next_merge`, `ui.box_at` and layout warnings in debug builds.
